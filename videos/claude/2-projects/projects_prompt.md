## How it is built

One flowing hand-drawn board, generated by `build_projects.py`, which imports the
shared engine (`from excalidraw_kit import *`) and holds only the composition: the
beat scaffold (`OX` / `WID` / `ACCENT` / `beat_head`) and this board's bespoke
illustrations. Never hand-place elements in the `.excalidraw`; change the build
script and regenerate.

```bash
python3 videos/claude/2-projects/build_projects.py      # rebuild this board
python3 preview.py videos/claude/2-projects/phlo-2.2-claude-projects.excalidraw out.png
python3 preview.py <scene> out.png XMIN XMAX            # close-up on one beat
python3 build_all.py                                    # rebuild all + Style-B guard
```

`finish()` self-checks palette discipline, the hand font, absence of frames, text
overflow and text/text collisions before writing. The board must build with
**0 collisions**, and `build_all.py` must print **GUARD PASS**.

## Layout

Thirteen beats, one uniform slot each - content ~1120 x 980 (~1.15 : 1), `GAP = 800`
of whitespace between slots. You record by panning left to right and framing one beat
at a time on a 14" laptop; the whitespace is the camera. No two neighbouring beats
share an accent, so every pan lands on a fresh colour.

## Non-negotiables

- **Frameless.** No Excalidraw `frame` elements (a hard Style-B guard failure - it is
  the rejected Style A's signature). No boxes round beats, no connector spine, no
  inter-beat arrows, white background. "Separate frames for the video" means separate
  beat slots.
- All text in the Virgil hand font via the kit (`fontFamily: 1`), `roughness: 1`,
  `lineHeight: 1.4`. Headings via the kit's `heading()` - no step-number circle, no
  highlighter sweep behind a title, no decorative sparkles. Body and explanation text
  stays ink/grey; accents carry headings, labels, shapes and fills.
- Lively Excalidraw palette only, colour-coded per beat. Colour comes from vivid
  elements, not from background washes behind beats.
- Charming primitive illustrations over emoji. Light rotation jitter on notes and
  chips. Bespoke one-off illustrations live in this build script, not in the kit; a
  kit edit re-styles every video and is a deliberate, rare act.
- **Examples generic, not Phlo-specific.** Everyday business scenarios only - a team
  tone guide, a customer reply template, Support / Ops. No branding or logo, no
  patient or clinical content. Phlo-native material belongs only in the live
  cut-aways, not on the board.
- Product proper nouns exact: Claude, Project, Artifact, Skill, MCP, Connector,
  Cowork, Claude Desktop.
- British English, hyphens not em dashes, fictional identifiers only.
- Where a beat carries a live cut-away, mark it with `demo_badge(...)` and use
  `[CUT TO CLAUDE DESKTOP]` / `[BACK TO BOARD]` in `projects_script.md`.
